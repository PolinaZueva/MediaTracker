# MediaTracker

**MediaTracker** - Android-приложение для ведения личной коллекции произведений: книг, манги, комиксов, аниме, фильмов, сериалов и другого контента. Пользователь самостоятельно выбирает категории, добавляет произведения и отслеживает прогресс чтения или просмотра.

Идея и назначение приложения описаны в [VISION.md](VISION.md).
## Основные пользовательские сценарии

### 1. Настроить категории

1. Пользователь выбирает интересующие его категории из предложенного списка.  
2. При необходимости создаёт свою категорию, указав её название.    
3. В дальнейшем может добавлять или переименовывать категории. Ненужную категорию можно удалить, если к ней не привязаны произведения.
### 2. Добавить произведение

1. Пользователь нажимает «Добавить произведение».    
2. Вводит название, выбирает категорию и статус («В планах», «В процессе», «Завершено», «Отложено», «Брошено»).
3. При необходимости задаёт единицу прогресса (серии, главы или страницы), текущее значение и общее количество. Для произведений без числового прогресса эти поля можно не заполнять.    
4. По желанию выбирает изображение обложки из галереи.    
5. Сохраняет запись. Она появляется в коллекции; без обложки отображается заглушка.
### 3. Обновить прогресс и статус

1. Пользователь открывает произведение из общего списка.    
2. Меняет статус или вводит актуальный прогресс напрямую, например с 5 на 50 глав.    
3. Сохраняет изменения; новые значения отображаются в карточке и списке.
### 4. Найти произведение в коллекции

1. Пользователь открывает общий список.    
2. Ищет произведение по названию либо выбирает фильтр по категории и статусу.    
3. При необходимости сортирует список по названию или дате добавления.    
4. Открывает найденное произведение для просмотра подробной информации.
### 5. Изменить или удалить произведение

1. Пользователь открывает карточку произведения.    
2. Редактирует название, категорию, статус, прогресс или обложку либо удаляет запись.    
3. Изменения отражаются в общем списке.
### 6. Вернуться к коллекции позже

1. Пользователь закрывает приложение.    
2. При повторном запуске ранее добавленные произведения, категории, обложки, статусы и прогресс сохраняются.    
## Критерии готовности 

Приложение считается готовым, если выполняются следующие условия:
- Приложение запускается на Android-устройстве или эмуляторе без подключения к интернету.    
- Пользователь может выбрать готовые категории, создать и переименовать собственные, удалить пустую категорию.    
- Можно добавить произведение с названием, одной категорией и статусом, в том числе сразу отметить его завершённым.    
- Можно указать текущий прогресс напрямую, выбрать единицу измерения и при необходимости общее количество; допускаются произведения без числового прогресса.    
- Можно выбрать обложку из галереи, заменить или убрать её; при отсутствии обложки отображается заглушка.    
- Работают общий список и экран подробной информации с переходами между ними.    
- Можно изменить данные произведения и удалить его из коллекции.    
- Работают поиск по названию, фильтрация по категории и статусу, сортировка по названию и дате добавления.    
- Категории, произведения, статусы, прогресс и обложки не пропадают после закрытия и повторного запуска приложения.
## Планируемые технологии

- **Kotlin** - язык разработки.    
- **Jetpack Compose** - пользовательский интерфейс.    
- **ViewModel, StateFlow, Coroutines** - управление состоянием и асинхронными операциями.  
- **Room** - локальная база данных.    
- **Navigation Compose** - переходы между экранами.
